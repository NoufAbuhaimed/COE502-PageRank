## 2. Raw data appendix

The PDF asks for the raw timings "in the report appendix or in a separate csv file so that the
reported plots can be reproduced". The CSV files in `results/` are the separate files; in the
appendix, list them and say how to regenerate the plots:

| File | Contents |
| --- | --- |
| `results/raw_timings.csv` | Every timing run (version, run, graph, threads, schedule, iterations, time) |
| `results/summary.csv` | Medians, speedup, efficiency and Karp–Flatt per configuration |
| `results/correctness.csv` | Serial vs OpenMP rank comparison |
| `results/convergence.csv` | Runs with the stopping rule |
| `results/thread_times.csv` | Per-thread busy times |
| `results/system_info.txt` | Full `lscpu` output of the test machine |

Reproduce everything: `make && make check && make bench && make plots && make imbalance`.

If you also want the raw timings inside the document, this prints them as one Markdown table
(560 rows, long):

```bash
uv run python - <<'EOF'
import csv
rows = list(csv.reader(open("results/raw_timings.csv")))
print("| " + " | ".join(rows[0]) + " |\n|" + "|".join(" --- " for _ in rows[0]) + "|")
for r in rows[1:]:
    print("| " + " | ".join(r) + " |")
EOF
```
