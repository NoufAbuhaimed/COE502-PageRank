# Q4 — Performance visualization

All the figures the report needs: what each one shows, how to regenerate it, how to get it from
the server into the Google Doc, and a caption to start from. Needs the benchmark results from
[Q1](Q1.md) and the profiling run from [Q3](Q3.md#1-profile-per-thread-work-load-imbalance).

PDF requirement: "Plot execution time, speedup, and efficiency versus thread count for both graph
distributions. Use a separate plot or clear series for each scheduling policy." Plots are required
for at least the medium and large inputs.

---

## 1. Generate all plots (on the server)

```bash
cd ~/COE502-PageRank
make plots                   # scaling_*.png, speedup_overview.png, chunk_sweep.png
ITERS=200 make imbalance     # thread_imbalance.png (skip if already done in Q3)
ls -l plots/
```

## 2. Download the plots to your laptop

**If you pushed from the server** (Q1 §9), on the laptop:

```bash
cd ~/"COE502_Project/page-rank"
git pull
open plots/
```

**Otherwise**, copy them directly (on the laptop):

```bash
cd ~/"COE502_Project/page-rank"
scp -r <user>@<server>:~/COE502-PageRank/plots .
open plots/
```

In the Google Doc: **Insert → Image → Upload from computer**, one image per figure slot.
